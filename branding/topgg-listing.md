## Deskripsi panjang

```markdown
# 🐤 Finch — bot seru buat semua server Discord!

Finch adalah bot Discord serbaguna **berbahasa Indonesia** dengan 138+ slash
command. Semua fitur bisa diatur lewat **dashboard web**, tanpa perlu hafal
config. Ketik `/bantuan` di server untuk menjelajahi semuanya lewat menu
dropdown interaktif.

## 🎮 Ekonomi & Game
/saldo, /daily, /kerja, /transfer, /top-koin — kumpulkan koin, buka toko,
nabung di bank berbunga, ikut lotre & lelang, main saham, atau adu untung di
minigame (blackjack, dadu, susun kata, trivia, suit). Ada quest harian,
season yang ke-reset, dan prestige buat yang paling rajin.

## 📈 Leveling
Dapatkan XP dari chat & voice call, naikkan level, pamerkan kartu rank
buatanmu (/rank), kejar role reward tiap level, dan adu peringkat di
leaderboard server.

## 🛡️ Moderasi
AutoMod (anti-spam, anti-invite, anti-caps, filter kata kasar), warn, mute,
kick, ban, purge, lockdown darurat, anti-raid, slowmode otomatis, plus
mod-log yang mencatat 25 aksi terakhir.

## 🎉 Komunitas
Giveaway otomatis (bisa pakai syarat role & jadwal, ada reroll), polling
tombol, starboard ⭐, self-role reaksi, saran member, tiket support privat,
temp voice channel buat mabar, pengingat ulang tahun, bump reminder, dan
event + RSVP.

## 🤖 Utilitas
Status AFK otomatis, reminder via DM, embed builder, pengumuman terjadwal,
auto-responder, notifikasi YouTube & Twitch, invite tracker, dan statistik
server real-time.

## 🌐 Dashboard Web
Atur welcome message, XP rate, ekonomi, AutoMod, starboard, self-role, dan
giveaway langsung dari browser — perubahan tersinkron ke bot dalam hitungan
detik.

---
Punya saran fitur atau butuh bantuan? Gabung ke server support kami. 💛
```
